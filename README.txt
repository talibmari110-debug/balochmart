BALOCH MART - SIMPLE SEO WEBSITE

Files:
- index.html       Homepage
- products.html    Products page with search
- about.html       About page
- contact.html     Contact page
- css/style.css    Responsive styling
- js/script.js     Mobile menu, product search and demo contact form
- robots.txt       Search-engine crawler instructions
- sitemap.xml      XML sitemap

IMPORTANT BEFORE PUBLISHING:
1. Replace https://www.balochmart.com/ with your real domain in:
   - all canonical tags
   - sitemap.xml
   - robots.txt
   - Open Graph URL values
2. Replace the demo phone number and email with your real details.
3. Replace emoji product placeholders with real product images and useful ALT text.
4. If the contact form needs to actually send messages, connect it to a backend/form service.
5. Upload the whole folder to your hosting public_html (or equivalent).
6. Submit sitemap.xml in Google Search Console after the site is live.
